# 【书刊22】 社会保障制度研究代际契约与改革路径

> 政策研究·社保

## 关于本书

社会保障是市场经济底层支柱，却常被讨论成情绪议题。本书把它还原为公式：缴费率τ＝替代率s×抚养比D。从恒等式出发：抚养比正从2.6:1滑向2050年的1.5:1，不触动公式的话术都绕不开算术。逐章讨论替代率选择、延迟退休的人口学依据、个人账户空账、全国统筹含义与代际契约的政治经济学。测算过程全部展开。
